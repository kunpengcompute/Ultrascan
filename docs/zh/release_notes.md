## V5.8.0

### V5.8.0新增特性

|特性描述|更新说明|
|--|--|
|mcsheng算法优化|基于鲲鹏920新型号处理器新增mcsheng算法优化。|
|正则匹配反馈优化技术|在AArch64平台新增运行期采集、feedback生成和反馈编译闭环；该能力默认关闭，需在构建时显式开启。|
|Grey配置优化|优化Grey配置方式，支持通过公开API设置与复位进程级Grey配置。|
